# 超级管理员全局功能开放管理

## 目标

新增独立 `SUPER_ADMIN` 角色，由超级管理员在“系统设置 → 功能开放管理”中控制左侧一级功能是否开放。关闭功能后隐藏所有主要前端入口并阻止直接访问，但不删除数据、不停止后台任务。

## 角色规则

- `SUPER_ADMIN` 继承 `ADMIN` 的全部权限。
- 只有 `SUPER_ADMIN` 可以修改全局功能开关和查看开关审计记录。
- 普通管理员不能创建、禁用或重置超级管理员账户。
- 系统必须至少保留一名有效超级管理员。
- 生产管理员引导脚本创建或修复的是超级管理员；迁移时若尚无超级管理员，提升最早创建的有效管理员。

## 功能目录

左侧可点击菜单项是一级功能，“工作区 / 自动化 / 系统”只是分组标题。

| 功能 | 可关闭 | 规则 |
| --- | --- | --- |
| 工作台 | 否 | 登录默认落点，始终开放 |
| 稿件管理 | 是 | 关闭后隐藏菜单并阻止直达 |
| 媒体库 | 是 | 关闭后隐藏菜单并阻止直达 |
| 视频创作 | 是 | 最终可用还要求视频服务能力可用 |
| 审核台 | 是 | 与稿件管理分别控制 |
| 选题中心 | 是 | 工作台中的选题入口和内容同步隐藏 |
| 自动发布 | 是 | 仅关闭用户入口，不停止已有调度或运行中任务 |
| 计费管理 | 是 | 仅关闭管理入口，计费和支付回调继续运行 |
| 账号管理 | 是 | 普通管理员不可用；超级管理员保留受保护入口 |
| 系统设置 | 否 | 始终为管理员开放，功能管理页签仅超级管理员可见 |

最终可用状态为：全局功能已开放、当前角色有权限、依赖服务能力可用。

## 操作与审计

- 所有功能默认开放；数据库不存在对应行时也视为开放。
- 关闭功能必须填写原因，开放原因可选。
- 每次真实状态变化记录功能、前后状态、操作人、原因和时间。
- 设置页显示最近操作信息，并可查看单项操作历史。
- 工作区分组内没有可见菜单项时，隐藏分组标题。

## 关闭后的访问行为

- 前端隐藏对应左侧菜单和工作台快捷入口。
- 通过收藏地址或历史记录直达时显示统一“此功能当前未开放”页面。
- 对标记了功能要求的 HTTP 入口返回 `FEATURE_DISABLED`；后台内部调用不经过 HTTP 功能守卫，因此调度、计费和已有任务不被停止。
- 功能状态读取失败时前端按默认开放降级，避免配置故障导致全站菜单消失。

## 非目标

- 不做按部门、用户或角色分别配置。
- 不做批量开关、定时开关、审批流或消息通知。
- 不做菜单改名、图标和排序管理。
- 功能开关不替代原有 RBAC 权限。
